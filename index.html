Cascade failure root-cause triage

Enter one cycle's developmental cascade. Each transition is tested against its benchmark (exact binomial), gated for statistical power (minimum-sample gate), and read across the cascade with adapted Westgard rules. Output is a triage hypothesis — A) biological, B) procedural, or C) non-attributable — not a diagnosis.

Cycle counts

Benchmarks & expected rates (edit to your validated lab values)
Core transitions (maturation / fertilization / cleavage / blastulation) use the Vienna competency values 75 / 60 / 95 / 40%, applied via Van Der Kelen et al. 2026; cleavage and blastulation both use 2PN as denominator (Vienna convention). Extended transitions use the Vienna Consensus (2017): oocyte recovery is a Vienna RI (80–95%; reflects stimulation/retrieval, not laboratory culture), implantation uses the Vienna blastocyst-stage competency ≥35% (benchmark ≥60%; multifactorial — uterine receptivity, transfer policy), and the usable-blastocyst rate (usable blastocysts / 2PN) uses a literature-weighted competency of ~40% (Chaillot 2024 and Hammond & Morbeck 2019 converge at ~40–41%; Datta 2025, n=14,156, reports a broader utilisation rate nadir ~45%) — not a consensus value, so confirm against your own baseline. Minimum-sample gates are OZEMA-derived only for the four core transitions; for the extended transitions they are author-defined. All values are editable to your validated baseline.

Developmental cascade

Resolve biological vs procedural — concurrent controls + patient history

The single-cycle verdict above is a weak discriminator. Concurrent sibling-batch controls are the strong one: for each flagged stage, enter how many concurrent cycles (same session / incubator / media lot / operator, different patients) were also low there, and whether the block recurred in this patient. Fixed threshold: a stage is “shared” when ≥50% of concurrent cycles are also low.

2×2 logic — shared & not recurrent → procedural (B); recurrent & not shared → biological (A); shared & recurrent → both; neither → still ambiguous. Needs ≥2 concurrent cycles.

How attribution is decided

A stage is read only if its denominator meets the OZEMA minimum sample (else → C non-attributable: under-powered). With adequate power, a rate at/above benchmark passes; a rate below benchmark that is not significant on the one-sided exact binomial test (P≥0.05) → C non-attributable: within chance. A significant drop is a real failure: if it is isolated to one stage, biology and that step's technique are co-primary and genuinely ambiguous in a single cycle → the tool shows both and the disambiguating evidence; if flagged stages are contiguous / systemic (Westgard 2₂ₛ / 4₁ₛ pattern), a procedural-environmental cause is prioritised. A single cycle can rarely separate biology from process on its own — concurrent sibling-batch cycles, the patient's cross-cycle history, and QC logs remain the confirmatory step.

Adapted Westgard rules

Stage transition ratios are converted to z-scores against benchmark (binomial SD) and read as an ordered series. This is a heuristic adaptation of Westgard multirules to the developmental cascade, not analytical-run QC on a control material; the stages are not independent replicate measurements, so treat fired rules as pattern flags, not formal control violations.

Notes & caveats

Benchmarks should be your laboratory's own validated values. Implantation is a clinical, highly multifactorial endpoint (embryo + endometrium + transfer) and is only weakly a lab-process metric; single transfers are statistically uninformative. This tool is a hypothesis-generating triage aid; it does not diagnose a patient or certify a process.
